# context: 덱에 쓸 원자료

덱의 수치와 사실은 이 폴더의 자료와 워크스페이스의 원자료에서만 가져온다. `/bmc-ppt`는 여기서 읽은 내용을 덱 폴더의 `facts.md`(팩트 원장)에 출처와 함께 옮겨 적고, 원장에 없는 수치는 덱에 쓰지 않는다.

넣어 두면 좋은 자료:

- 지표: 이용자 수, 리텐션, 전환율의 최신 값과 측정 기간 (지표 정의서나 대시보드 캡처를 함께 두면 좋다)
- 시장: 시장 규모 계산에 쓰는 근거 자료와 그 출처
- 고객: 도입 사례, 인터뷰 기록, 공개해도 되는 고객사 이름
- 제품: 화면 이미지, 요금제, 도입 절차
- 회사: 팀 이력, 연혁, 투자 유치 이력

자료마다 작성일과 수치의 측정 시점을 적어 둔다. 측정 시점이 없는 수치는 원장에서 "확인 필요"로 표시된다.
